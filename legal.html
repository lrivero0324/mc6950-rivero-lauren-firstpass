About this prototype

FirstPass is a class project. These notes explain how the demo works. They are not a company policy.

User Agreement

This prototype is for a class demonstration. Sample accounts use the password demo. Please do not enter real personal information, or a password you use anywhere else.

Privacy Policy

FirstPass does not send your information to a server. Profiles, invitations, and sign-in details stay in this browser.

Cookie Policy

This prototype does not use tracking cookies. It uses local storage so the demo can remember your session on this device.

Accessibility

Forms have visible labels. Buttons and links have names. Focus is outlined when you move with the keyboard. If something is hard to use, that is a limit of this class prototype.
